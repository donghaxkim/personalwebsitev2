A 4-step animated pipeline: dot product → scale → softmax → weighted sum. Each step shows the actual matrices transforming. Users click "Next Step" to advance, seeing numbers change in real time. The math formula highlights which part is active.

Interactive Worked Example with Sliders

Section: "a worked example"

Instead of static numbers, let users drag sliders to change the Q/K vectors and watch the dot products, scaled scores, and softmax outputs update live. "What happens if cat's query changes?" — they can find out. Builds real intuition for how vectors determine attention.

Multi-Head Attention Visualizer

Section: "multi-head attention"

Show 4 attention heads side-by-side on the same sentence, each learning different patterns. One head tracks subject-verb, another tracks positional proximity, etc. Users can toggle heads on/off and see how the concatenated output changes. Makes the "different angles" concept concrete.
